## How to Read These Charts

**For Investment Decisions:** Charts 02 (what to buy), 05 (what to expect), 07 (what can go wrong)

**For Quarterly Reviews:** Charts 01 (current state), 10 (FIRE progress), 11 (diversification check)

**For Understanding Rationale:** Charts 03 (why this cap mix), 04 (why these sectors), 08 (why gold-heavy), 09 (why step-up matters), 13 (why SIP on 1st)

**For Migration Tracking:** Chart 06 (are legacy funds draining on schedule?)

**For Tax Planning:** Chart 12 (when to harvest, when ELSS unlocks)

## Regenerating Charts

```bash
cd /path/to/finance
python3 scripts/generate-all-charts.py
```

Requires: `matplotlib`, `numpy`, `json` (standard library)
Data source: `data/monthly_holdings.json` (180-month simulation)

---

*All charts use consistent color coding: Blue=UTI N50, Green=PPFAS, Orange=Motilal Mid, Red=Bandhan Small, Gold=Gold FoF, Silver=Silver FoF, Purple=EPF*
