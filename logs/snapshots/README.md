# Portfolio Snapshots

Quarterly portfolio value snapshots for tracking growth over time.

## How to Use

After each rebalancing check, record the portfolio value here.
Run `rebalance check` in Copilot CLI or fetch from Kite.

## Format

Each file: `YYYY-MM.md` — one snapshot per quarter.
